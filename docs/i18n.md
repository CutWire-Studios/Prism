# Translations

Prism's source language is English. C++ strings use `tr()` and QML strings use `qsTr()`.
The catalog is `i18n/prism.ts`, which lupdate maintains from the sources.

## Updating the catalog

After adding or changing a translatable string, run:

```sh
cmake --build build --target update_translations
```

Commit the updated `i18n/*.ts` files. The `Translations` CTest fails when the committed
catalogs are stale:

```sh
ctest --test-dir build -R Translations --output-on-failure
```

Set `-DPRISM_AUTO_UPDATE_TRANSLATIONS=ON` to run lupdate as part of every build.

lupdate must have QML support (Qt's `lupdate` built with qtdeclarative). Without it, lupdate
deletes every QML string from the catalogs, so CMake skips the refresh and the Translations test.

## Adding a locale

1. Copy the source catalog to a locale catalog named with a Qt locale code:
   `cp i18n/prism.ts i18n/prism_fr.ts` (also `prism_pt_BR.ts`, `prism_zh_Hans.ts`, ...).
2. Translate it with Qt Linguist: `linguist i18n/prism_fr.ts`.
3. Rebuild. CMake picks up every `i18n/prism_*.ts`, compiles the `.qm` files into the
   binary under `:/i18n`, and lists the language in Settings > General.

Each locale catalog is refreshed by `update_translations` along with `prism.ts`.
